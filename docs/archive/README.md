# Archivio storico — StructuralSolver2D

Questo archivio conserva **versioni precedenti di documenti e note di rilascio**, per provenienza tecnica e confronti retrospettivi. I loro titoli e gli stati «gate pendente / checkpoint corrente» sono **fotografie storiche**, non descrivono lo stato attuale.

Per il lavoro corrente usare, nell'ordine: [`CURRENT_STATE.md`](../structural/CURRENT_STATE.md), [`docs/structural/roadmap.md`](../structural/roadmap.md), [`ENGINEERING_AND_VALIDATION_RULES.md`](../structural/ENGINEERING_AND_VALIDATION_RULES.md), [`HANDOFF_NUOVA_CHAT.md`](../../HANDOFF_NUOVA_CHAT.md), [`CHANGELOG.md`](../../CHANGELOG.md) e [`README.md`](../../README.md).

- `README_PRE_G7.md`: vecchio README con note milestone concatenate.
- `CHANGELOG_PRE_G7.md`: cronologia integrale precedente, conservata senza riscriverla.
- `ai-handoff-storico.md`: vecchi checkpoint per le singole milestone.
- `roadmap_PRE_G7.md`, `vision-and-roadmap_PRE_G7.md`: precedenti versioni con molte informazioni non più correnti.
- `roadmap_PRE_F0_2026-10-25.md`: roadmap immediatamente precedente a F0, conservata per provenienza.
- `HANDOFF_PRE_F0_2026-10-25.md`, `NUOVA_CHAT_MESSAGGIO_PRE_F0_2026-10-25.txt`: indicazioni di ripresa storiche, sostituite con versioni essenziali.
